# 🎓 MStudy Pro

### مطالعه هوشمند، تمرکز بیشتر، پیشرفت سریع‌تر

MStudy Pro یک اپلیکیشن مدرن برای مدیریت مطالعه، افزایش تمرکز، مرور فاصله‌دار و پیگیری پیشرفت تحصیلی است.

## ✨ امکانات

- ⏱️ تایمر تمرکز (Pomodoro و حالت سفارشی)
- 📚 مدیریت منابع و یادداشت‌ها
- 🧠 فلش‌کارت و مرور فاصله‌دار (Spaced Repetition)
- 📈 آمار و پیگیری پیشرفت
- 🎯 سیستم XP و Level
- 💾 پشتیبان‌گیری و بازیابی اطلاعات
- 🌙 حالت تاریک و تم‌های مختلف
- 📱 قابلیت نصب به عنوان PWA
- 🌐 پشتیبانی از اجرای آفلاین با Service Worker

## 🛠️ فناوری‌ها

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Progressive Web App (PWA)
- Service Worker

## 🚀 اجرا

مخزن را دریافت کنید:

```bash
git clone https://github.com/amirgt206-hash/MStudy_-_-_Pro.git
```

سپس فایل `index.html` را در مرورگر اجرا کنید.
